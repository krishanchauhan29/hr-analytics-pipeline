# 👥 HR Analytics Pipeline

An end-to-end HR analytics pipeline with SQL-style queries, attrition analysis, and interactive dashboard built on the IBM HR Employee Attrition dataset.

## 🔴 Live Demo
👉 [Click here to view the live dashboard](https://hr-analytics-pipeline292003.streamlit.app/)

## 📌 Key Business Insights
- Sales department has highest attrition **(20.6%)**
- Overtime employees are **3x more likely** to leave (30.5% vs 10.4%)
- Low salary band has **28.6% attrition** — highest risk group
- Fresh employees **(0-5 yrs)** at 28.2% attrition risk

## 🛠️ Tech Stack
- **Python** — Pandas, NumPy, Matplotlib, Seaborn, Plotly
- **SQL-Style Analytics** — Complex aggregations, window-style queries
- **Streamlit** — Interactive dashboard with filters
- **Excel** — Automated multi-sheet reporting via openpyxl

## 🚀 Run Locally
```bash
git clone https://github.com/krishanchauhan29/hr-analytics-pipeline.git
cd hr-analytics-pipeline
pip install -r requirements.txt
streamlit run dashboard/app.py
```
